# Selenium Appium — SauceLabs Mobile

## Test APK
The app under test is the SauceLabs Android sample app v2.7.1 (package `com.swaglabsmobileapp`), stored under `apps/`. The automated flow buys `Sauce Labs Backpack` + `Sauce Labs Bike Light`: login via the in-app `standard_user` autofill tap (no typing), button/image visibility checks along the way, and order success asserted on the mascot image.

## Tech Stack
| Tool | Version |
| ---- | ------- |
| Java / Maven | JDK 21 / 3.9+ |
| Appium Java Client / Selenium | 10.1.1 / 4.42.0 |
| Cucumber / JUnit / Allure | 7.14.0 / 5.10.3 / 2.27.0 |
| Appium Server / Android Emulator | 3.x / e.g. `emulator-5554` |

## Prerequisites
- JDK 21, Maven 3.9+, Android SDK + ADB, Android Emulator, Appium Server 3.x (verified with `appium --version` = 3.7.0)
- A running emulator, e.g. `emulator-5554` (check with `adb devices`)
- Allure CLI for viewing the report (`npm install -g allure-commandline` and ensure `allure` is on PATH)

## Setup
```bash
# 1. Set environment variables (adjust paths to your machine)
# ANDROID_HOME=C:\Users\<you>\AppData\Local\Android\Sdk
# JAVA_HOME=C:\Program Files\Java\jdk-21
# Add to PATH: %ANDROID_HOME%\platform-tools, %ANDROID_HOME%\emulator, %JAVA_HOME%\bin

# 2. Start the emulator and verify it is attached
emulator -avd <your_avd_name>
adb devices

# 3. Start Appium
appium --port 4723

# 4. Verify dependencies (Selenium must resolve to 4.42.0)
mvn dependency:tree

# 5. Compile
mvn test-compile
```

## Run
```bash
# Defaults: deviceName=emulator-5554, server=http://127.0.0.1:4723/
mvn test

# Override when needed:
mvn test -DdeviceName=emulator-5554 -Dudid=emulator-5554 -DappiumServerUrl=http://127.0.0.1:4723/
```

## Reports
- Cucumber HTML: `target/cucumber-report.html` (generated by `mvn test`)
- Allure:
  ```bash
  mvn clean test
  allure serve target/allure-results
  ```
  Results are written to `target/allure-results` (see `allure.properties`). If the report shows 0 test cases, make sure you serve `target/allure-results`, not the legacy `allure-results/` folder at the project root.
